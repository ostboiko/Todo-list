# Todo-list

Python 3.11
Django 5.0.3

welcome to my Django project called Todo_list. Here you can add your tasks for the whole week and mark whether you have 
completed them or not

First, we have to start up Django's development server.
 -python manage.py runserver

## Installation
Python3 must be already installed


## shell
git clone https://github.com/ostboiko/Todo-list


## Features
* Managing your weekly tasks
* Mark executive tasks
* Update Task&Tag
